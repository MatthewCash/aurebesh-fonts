# Aurebesh Fonts

Nix package for an Aurebesh font based on Aurebesh AF Legends.

Generated from https://github.com/AurekFonts/AurekFonts.github.io/tree/master/AurebeshAF

The generated `aurebesh.otf` has these changes from AurebeshAF:

- lowercase letters keep the original Aurebesh AF Legends glyphs
- capital `A-Z` glyphs are mirrored horizontally
- lowercase digraph ligatures stay normal
- capitalized and all-caps digraph ligatures use mirrored glyphs
